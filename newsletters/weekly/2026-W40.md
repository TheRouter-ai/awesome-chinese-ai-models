## Coding Agents & Developer Tooling

**Qwen Code v0.24.4** — [Qwen Code v0.24.4](https://github.com/QwenLM/qwen-code/releases/tag/v0.24.4) expanded the project's operational surface across CLI, daemon, web, mobile, Java, and remote-workspace workflows. Notable additions include batched workspace session catalogs, plan provenance and drift reporting, SSH workspaces without a remote daemon, expiring QR pairing, encrypted mobile connection profiles, managed runtime attestation, persistent Java tool executions, and moving bubblewrap sandboxing closer to tool execution. The release also improved review coverage, remote folder browsing, edit-diff approvals, Live sessions, and OpenTUI parity. Qwen published a nightly and a [v0.24.5 preview](https://github.com/QwenLM/qwen-code/releases/tag/v0.24.5-preview.0) in the same window, signaling continued rapid iteration after the stable release.

**DeepSeek Harness v0.1.7 alpha** — DeepSeek published [v0.1.7-alpha.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-alpha.1) and [v0.1.7-alpha.2](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-alpha.2). Alpha 1 introduced richer session pinning and archiving, background commands and workflows, live background-job output, spreadsheet previews, side-by-side change review, more compact displays for agent state, and a streamlined first-run experience. It also moved the official DeepSeek adapter to the Messages API and tightened Windows sandbox deletion boundaries. Alpha 2 focused on polish and recovery: steadier scrolling and history navigation, preserved multiline queued prompts, better agent-team guidance, smarter npm-registry selection, fixes for stalled sessions after background work, and web-client reconnection after server restarts.

**OpenBMB PilotDeck v2026.09.23** — [PilotDeck v2026.09.23](https://github.com/OpenBMB/PilotDeck/releases/tag/v2026.09.23) was a compact maintenance release. It added workspace-upload progress, rejected duplicate filenames, prevented concurrent YAML corruption, improved responsive workspace panels, and refined Windows and macOS background lifecycle behavior.
